# AWS Architecture Icons

The SVG files in this directory are taken unchanged from the AWS Architecture Icons asset package, release of 31 July 2026, published at https://aws.amazon.com/architecture/icons/. They were renamed; nothing else was done to them.

They are used by `analysis/architecture.py` to draw the architecture diagrams of this study. AWS says on that page: "We allow customers and partners to use these toolkits and assets to create architecture diagrams." The icons belong to Amazon Web Services and are not part of what this repository's author offers under any licence of its own.
